# Saída dos builds

- Windows: `windows/DesktopPets-Setup.exe` (`npm run production:windows` em Windows).
- Linux: `linux/desktop-pets.deb` (`npm run production:linux` em Linux).

As subpastas estão vazias até uma compilação bem-sucedida. Não distribua `src`, `src-tauri/target`, `node_modules` ou este README: envie somente o instalador apropriado. O script remove o instalador antigo antes de compilar; confira a data e o SHA256 exibidos pelo script antes de compartilhar.
